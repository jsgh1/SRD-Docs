# Plan de actualización del Manual de usuario final

**Originales:** [Word](../entregables-originales/06_Manual_de_usuario_final_SRD.docx) · [PDF](../entregables-originales/06_Manual_de_usuario_final_SRD.pdf). El lector es un integrante de junta, no un desarrollador: escribir pasos concretos, capturas actuales y consecuencias de las acciones sin lenguaje de API salvo una nota de solución de problemas.

## Cambios para integrar en el flujo del manual

1. **Acceso:** mostrar la primera pantalla real, cómo se usa código/enlace de junta, correo, contraseña, aceptación de términos y MFA. Distinguir código de junta de contraseña. Explicar invitación y asignación posterior de roles según permisos, sin publicar credenciales de ejemplo como si fueran permanentes.
2. **Perfil e idioma:** guiar el selector Español/English en Perfil y su persistencia hasta que la persona vuelva a cambiarlo. Explicar con un ejemplo simple que nombres, mensajes y otros textos redactados por la junta no se traducen automáticamente; la junta administra versiones ES/EN de sus etiquetas y textos configurables. Aclarar que registros antiguos sin inglés pueden mostrar su texto original.
3. **Pantallas y formularios vigentes:** revisar cada paso de Personas (Registro, Lista, Consultar, filtros avanzados, fotos, planilla y exportación), Calendario, Tesorería informativa, Inventario, Carpetas, Contactos, Chat, Notificaciones, Auditoría y Configuración según rol. Comparar botones y nombres contra la web actual antes de usar capturas; retirar instrucciones de menús que ya no existen.
4. **Chat:** explicar menú de acciones dentro de cada mensaje, borrado propio para ambos y recibido solo para uno, visor/zoom de imagen, fijados, vista previa de adjuntos, composición larga, nota de voz con pausa y reproducción, estados Escribiendo/Grabando/Llamando, y registro de llamadas perdidas/finalizadas. Distinguir lo probado localmente de disponibilidad entre redes o dispositivos aún no aceptada.
5. **Avisos y errores:** diferenciar Marcar como leído de Descartar, aviso de llamada, error con Reintentar, carga/espera, guardado de resultado incierto y antivirus no disponible. Dar una acción segura: comprobar el registro antes de repetir un guardado y pedir asistencia si una carga está bloqueada.
6. **Matriz de roles:** incluir una tabla compacta con funciones visibles y operaciones que cada rol puede realizar, usando [PERMISOS.md](../PERMISOS.md). Aclarar delegaciones configurables, por ejemplo lectura de Carpetas, y que el servidor decide el permiso final.

## Calidad de la entrega

Usar ES claro y consistente, pies de captura con versión, pasos numerados, ejemplos ficticios y advertencias solo donde el usuario debe decidir. Verificar a 320 px y escritorio los procedimientos fotografiados. No llamar «certificada» a la web: [WEB_ACEPTACION.md](../WEB_ACEPTACION.md) y [PENDIENTES-WEB-2026-10-16.md](../PENDIENTES-WEB-2026-10-16.md) mantienen trabajo abierto.
